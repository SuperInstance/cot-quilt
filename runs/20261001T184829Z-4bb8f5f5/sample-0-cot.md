## Why it is fair and cannot starve a cell

Let \(S\) be the set of cells that receive the token infinitely often. Initially the token is somewhere, so \(S\) is nonempty.

Suppose \(i\in S\). Then \(i\) receives the token infinitely often, so it passes the token infinitely often. Every \(K\)-th pass from \(i\) is forced to follow its fixed cyclic neighbor list. Since that list cycles through all direct neighbors of \(i\), every neighbor of \(i\) is eventually selected infinitely often. Therefore every neighbor of \(i\) is also in \(S\).

Thus \(S\) is a nonempty set closed under graph adjacency. Because the graph is connected, the only such set is the whole vertex set. Hence every cell receives the token infinitely often.

Therefore every cell receives the next unit of computation budget infinitely often. No cell can be starved forever.

The potential/resistance score biases the non-forced passes toward cells with higher \(P/R\), but the forced round-robin passes guarantee a minimum service rate. If the potentials and resistances are static and one simply always chose the locally maximal score, starvation would be possible; the forced local round-robin is the minimal safeguard that makes the no-starvation claim true.
